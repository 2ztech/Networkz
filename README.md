# Networkz

Switch command reference for Aruba AOS-S, Aruba AOS-CX, and HPE Comware.

Covers IP addressing, VLANs, inter-VLAN routing, static routes, SSH, Telnet, SNMPv2c/v3, STP, LLDP, DHCP relay, ACLs, port security, logging, NTP, and user management.

Toggle between OS types to see the correct syntax per platform.

**[Open Reference](https://2ztech.github.io/Networkz/)**
